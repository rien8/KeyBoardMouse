# mousekey — 用键盘控制鼠标（Windows 鼠标键替代品）

一个 Windows 小工具：按住数字键盘就能移动鼠标、点击、拖动、滚轮，
把 Windows 自带"鼠标键"那股发木的手感换掉。

- 4 ms 级运动引擎，加速曲线可调，慢速不跳格（亚像素累加）
- 斜向速度归一，不再比直向快 41%
- 键位按**扫描码**绑定，不受 NumLock 开关影响，面板里一键改键
- Dear ImGui 界面 + 托盘常驻，`exe` 约 560 KB，无任何 DLL 依赖

## 快速开始

1. 运行 `mousekey.exe`（首次运行会在同目录生成 `mousekey.ini`）。
2. 关闭窗口不是退出，只是最小化到托盘；托盘图标是绿色的表示已启用。
3. 按住小键盘 `8` 光标向上走，`4/6/2` 左/右/下，`7/9/1/3` 斜向。
4. 按 `5` 单击；按 `.` 右键单击；按住 `0` 可以拖着走。

> 默认为**启用**状态。第一次启动会自动把 NumLock 关掉（见 [NumLock 行为](#numlock-行为)）。

## 按键映射表

默认键位沿用 Windows 鼠标键的数字键盘，按下即生效（不需要点窗口）。
表格里的"扫描码"就是配置文件里的写法；扩展键在扫描码上加 `0x100`
（例如小键盘 `/` 是 E0 35，写作 `0x135`）。

### 移动

| 按键 | 扫描码 | 动作 | 鼠标效果 |
|---|---|---|---|
| `8` | `0x48` | 上 | 光标向上移动，按住速度按曲线增长 |
| `2` | `0x50` | 下 | 向下移动 |
| `4` | `0x4B` | 左 | 向左移动 |
| `6` | `0x4D` | 右 | 向右移动 |
| `7` | `0x47` | 左上 | 斜向，两个方向分量同时生效 |
| `9` | `0x49` | 右上 | 斜向 |
| `1` | `0x4F` | 左下 | 斜向 |
| `3` | `0x51` | 右下 | 斜向 |

斜向合速度与直向相同（`diagScale = 0.7071`，各分量 ×0.707），所以不会像
Windows 鼠标键那样斜着跑更快。想让斜向更快，把 `diagScale` 调到 1.0。

### 点击

| 按键 | 扫描码 | 动作 | 鼠标效果 |
|---|---|---|---|
| `5` | `0x4C` | 单击 | 按**当前模式**单击：默认左键，切到右键模式后变右键 |
| `/` | `0x135` | 5 切左键 | 把 5 的点击模式切回**左键**（面板顶部显示 `5 → 左键`） |
| `*` | `0x37` | 5 切右键 | 把 5 的点击模式切到**右键**（显示 `5 → 右键`） |
| `.` | `0x53` | 右键单击 | 固定右键单击，不受模式影响 |
| — | — | 中键单击 | 默认未绑定，可在面板里捕获 |

模式是运行时状态，不写入配置文件，启动时一律为左键。

### 按住 / 拖拽

| 按键 | 扫描码 | 动作 | 鼠标效果 |
|---|---|---|---|
| `0` | `0x52` | 按住 | 按下当前模式的键并保持，配合方向键即拖拽；**松开 0 自动抬起** |
| — | — | 释放按键 | 立即抬起所有由本工具按下的键；默认未绑定，作为应急动作保留 |

拖拽示例：按住 `0` → 按 `6` 移动 → 松开 `0`，完成一次选择/拖放。
由于松开 `0` 就自动抬起，正常使用不会出现"按键卡住"。

### 滚轮

| 按键 | 扫描码 | 动作 | 鼠标效果 |
|---|---|---|---|
| `+` | `0x4E` | 滚轮上 | 按住连续上滚，速度 = `wheelRate` 格/秒 |
| `-` | `0x4A` | 滚轮下 | 按住连续下滚 |

滚轮是**按时间累积**的：`wheelRate = 12` 表示按住 1 秒滚 12 格，
慢按不会因量化丢格。

### 与 Windows 鼠标键的差异

| 功能 | Windows 鼠标键 | 本工具 |
|---|---|---|
| 5 = 左键模式 | `/` | `/` |
| 5 = 右键模式 | `-` | `*` |
| 5 = 双键模式 | `*` | 不支持 |
| 双击 | `+` | 不支持（连按两下 5） |
| 滚轮 | 不支持 | `+` / `-` |
| 右键单击 | `-` 再 `5` | `.` 直接右键 |

原因：Windows 用 `-`/`+` 做模式与双击，而本工具把 `+`/`-` 给了滚轮，
所以模式切换挪到 `/` 和 `*`，机制一致、键位不同。

## 典型操作流程

**点一个按钮**
按住方向键移动 → 按 `5` 左键单击。

**右键菜单**
按 `.`（或先按 `*` 再按 `5`）→ 菜单弹出。

**拖动窗口 / 选中文本**
按 `0` 按住左键 → 方向键移动 → 松开 `0`。

**缓慢微调（对准 1 px 目标）**
短按方向键即可：起步速度 `vStart = 40 px/s`，一个 tick 只走 0.16 px，
累加器会把不足 1 px 的位移攒起来，表现为连续微动而不是"卡一下跳一格"。

**大面积移动**
按住方向键不放，速度在 `rampMs = 500 ms` 内爬到 `1600 px/s`。
按默认参数，4K 屏（3840×2160）对角线约 3 秒；把 `vMax` 提到 4000
可压到约 1.5 秒。

## 运动参数

面板"运动参数"里可实时改，改完立即生效（勾选"保存配置"或退出时写盘）。

| 参数 | 默认 | 可调范围 | 含义 |
|---|---|---|---|
| `vStart` | 40 px/s | 1 – 2000 | 按下瞬间的初速度。越小起手越稳，不会"窜" |
| `vMax` | 1600 px/s | 100 – 8000 | 满速，决定跨屏耗时 |
| `rampMs` | 500 ms | 1 – 5000 | 从 `vStart` 爬到 `vMax` 的时间 |
| `gamma` | 1.0 | 0.1 – 4.0 | 曲线弯曲度。`<1` 起手快；`>1` 起手慢、低速段长 |
| `diagScale` | 0.7071 | 0.5 – 1.0 | 斜向系数。`0.7071` 各向同性，`1.0` 斜向更快 |
| `wheelRate` | 12 格/s | 1 – 60 | 滚轮速度 |

速度曲线：

```
v(t) = vStart + (vMax − vStart) · min(t / rampMs, 1) ^ gamma
```

超出范围的值（手改 ini 写错）会自动回落到默认值，不会把程序搞坏。

## 界面与托盘

**面板**（填满整个窗口，随窗口缩放自适应）

| 区域 | 内容 |
|---|---|
| 顶栏 | `启用` 勾选框；实时显示当前方向输入、速度、`5 → 左键/右键` |
| 运动参数 | 上表 6 个参数，带 `(?)` 悬停说明 |
| 按键映射 | 每个动作一行，`捕获` 按钮录新键 |
| 杂项 | `启用时关闭 NumLock`、`记录 tick CSV` |
| 底部 | `保存配置` / `恢复默认` / `退出程序` |

**改键**：点某行的 `捕获` → 按目标键 → 完成（`Esc` 取消）。
和已有键冲突时会提示并拒绝，避免一个键绑两个动作。

**托盘**

| 操作 | 结果 |
|---|---|
| 左键单击图标 | 打开设置面板 |
| 右键 → 启用 / 停用 | 切换开关（图标绿色=启用，灰色=停用） |
| 右键 → 设置… | 打开设置面板 |
| 右键 → 退出 | 保存配置并退出 |

关闭窗口只隐藏，不退出。重复启动只会唤出已有实例的面板（单实例）。

## NumLock 行为

| 时机 | 动作 |
|---|---|
| 启动且为启用状态 | 关闭 NumLock |
| 面板勾选启用 / 托盘启用 | 关闭 NumLock |
| 停用 | 恢复 NumLock（当初是我们关的才恢复） |
| 退出程序 | 恢复 NumLock |

只在**本工具关掉过** NumLock 时才恢复，你自己关的状态不会被强行打开。

> 键位按扫描码识别，所以 NumLock 开或关都不影响功能；关掉只是为了
> 停用状态下数字键盘不再往外打字。

不想要这个行为：面板"杂项"里取消 `启用时关闭 NumLock`，
或把 ini 里的 `[misc] fixNumLock=0`。

## 配置文件

位置：**exe 同目录** `mousekey.ini`，纯文本，可直接手改，改完重启生效。

```ini
[motion]
vStart=40
vMax=1600
rampMs=500
gamma=1
diagScale=0.7071
wheelRate=12

[keys]
Up=0x48
Down=0x50
Left=0x4B
Right=0x4D
UpLeft=0x47
UpRight=0x49
DownLeft=0x4F
DownRight=0x51
Click=0x4C
RightClick=0x53
MiddleClick=0x0
Hold=0x52
Release=0x0
WheelUp=0x4E
WheelDown=0x4A
ModeLeft=0x135
ModeRight=0x37

[misc]
enabled=1
csvLog=0
fixNumLock=1
```

扫描码可用十六进制（`0x48`）或十进制（`72`）书写，`0x0` 表示不绑定。
扩展键在扫描码上加 `0x100`（如小键盘 `Enter` = `0x11C`、`Delete` = `0x153`）。

调试产物 `mousekey_ticks.csv`（勾选 `csvLog` 后下次启动生成，写在 exe 旁）：

```
t_ms,dt_ms,dir,v_px_s,dx,dy,wheel
4.000,4.000,0x1,52.48,0,0,0
8.438,4.438,0x1,66.21,0,0,0
```

用于客观核对加速曲线：`v` 应随时间单调上升，`rampMs` 后稳定在 `vMax`。

## 构建

要求：Visual Studio（MSVC）与 CMake；不需要任何第三方运行时。

```
call "C:\Program Files (x86)\Microsoft Visual Studio\...\vcvars64.bat"
cmake -S . -B build-release -G "NMake Makefiles" -DCMAKE_BUILD_TYPE=Release
cmake --build build-release --target mousekey
```

产物 `build-release/mousekey.exe`，约 560 KB。

已 vendored 的依赖（无需联网）：

| 依赖 | 版本 | 位置 |
|---|---|---|
| Dear ImGui | v1.93.0 | `third_party/imgui/` |
| doctest | v2.4.12 | `third_party/doctest/` |

Debug 构建：把 `-DCMAKE_BUILD_TYPE=Release` 换成 `Debug` 即可。

## 设计要点

- **三线程**：主线程（窗口/托盘/ImGui）、钩子线程（`WH_KEYBOARD_LL`）、
  引擎线程（移动注入）。渲染卡顿不影响移动手感。
- **引擎空闲不占 CPU**：无按键时阻塞在事件上（实测 4 秒 0 ms CPU），
  按下时钩子 `SetEvent` 唤醒，`timeBeginPeriod(1)` + `Sleep(4)` 跑 tick，
  全部松开后退回事件等待。
- **`dt` 用 `QueryPerformanceCounter` 实测**，不用名义 4 ms；定时器抖动被
  实测 `dt` 精确补偿，位移仍是速度对时间的严格积分。
- **亚像素累加 + 向零取整**：慢速时不足 1 px 的位移累积保留，正负方向时序对称。
- **按扫描码绑定**：NumLock 关闭时数字小键盘会发 `VK_UP` 等虚拟键，与方向键
  撞车；扫描码唯一。扩展键用 `0x100` 位区分（主 `Enter` `0x1C` vs 小键盘
  `Enter` `0x11C`）。
- **钩子吞掉已绑定的键**，并过滤长按产生的重复 down（否则加速曲线会被反复
  重置）。按键重复靠"按下状态表"判断，因为 `KBDLLHOOKSTRUCT` 不带 repeat 位。
- **注射侧按键状态机**：只抬起本工具真正按下的键，避免凭空产生
  `RIGHT_UP` 被 Windows 解释成右键点击。

更细的推导与实测数据见 [docs/DESIGN.md](docs/DESIGN.md)。

## 已知边界

- 目标程序以管理员身份运行时，本工具也需管理员运行（UIPI 限制）。
- UAC 安全桌面、部分全屏独占游戏内钩子不生效（系统行为，非本工具可解）。
- 一个键只能绑一个动作；冲突时面板会拒绝并提示。
- 不支持：惯性滑行、按应用切换配置、连点、多套配置、5 的双键模式。
- 托盘图标不显示气泡通知；模式切换无声音提示（只看面板顶部，或看光标动作）。

## 常见问题

**按 5 变成右键了？**
`5` 的点击模式被切到右键了。按 `/` 切回左键，或看面板顶部是否显示
`5 → 右键`。按 `.` 则是固定右键，与模式无关。

**按了没反应？**
先看托盘图标是不是灰色（停用），再看面板顶部"输入"是否有方向在亮。
如果目标程序是管理员权限，本工具也需要管理员权限。

**NumLock 又被打开了？**
停用或退出时会恢复。再次启用会自动关闭；如果彻底不想动 NumLock，
把"杂项"里的 `启用时关闭 NumLock` 取消勾选。

**数字键会往别的程序里打字吗？**
已绑定的键会被钩子吞掉，不会漏出去。

**想换成 WASD？**
面板里逐行点 `捕获`，按下目标键即可；不需要改代码或配置文件。

**配置乱了怎么恢复？**
面板底部 `恢复默认`，或直接删掉 `mousekey.ini` 重启。

**能开机自启吗？**
当前版本没有内置开关；可以把 `mousekey.exe` 的快捷方式放进
`shell:startup` 目录。
