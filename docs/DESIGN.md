# mousekey 设计方案

本文件来自 2026-11-21 的方案讨论(session-c1b7eed5),是本项目的实现依据。
已确认决策:**默认键位沿用 Windows 鼠标键的数字键盘**;GUI 用 Dear ImGui(Win32/DX11 后端)。

## 背景与根因

Windows 鼠标键"移动手感差",是三件事叠加,而系统只解决了一半:

1. **事件频率太低**:每次按键只移动一格,响应只有几十赫兹,一顿一顿。
2. **位移按整数像素量化**:慢速时"一次不足 1 像素"被丢掉,要么不动,要么突然跳过。
3. **加速曲线不可调**:起步速度、满速时间常数写死,跨高分屏满速又不够快。

本工具的核心是一个 **4 ms 精度的运动引擎**,GUI 只是它的参数面板。

## 运动模型

每 4 ms 一个 tick,速度按按住时长生长:

```
v(t) = vStart + (vMax - vStart) * pow(min(t / rampMs, 1), gamma)
```

| 参数 | 含义 | 默认 | 手感影响 |
|---|---|---|---|
| `vStart` | 按下瞬间的速度 px/s | 40 | 起手会不会"窜" |
| `vMax` | 满速 px/s | 1600 | 跨屏耗时 |
| `rampMs` | 从 vStart 爬到 vMax 的毫秒数 | 500 | 粗调转微调的过渡 |
| `gamma` | 曲线弯曲指数 | 1.0 | <1 起手快,>1 起手慢、低速段长 |
| `diagScale` | 斜向系数,0.7071 = 等比 | 0.7071 | 斜向是否比直向快 |
| `wheelRate` | 滚轮速度,格/s | 12 | 滚动快慢 |

位移在内部存成浮点:`acc += v * dt`,每 tick 只发出整数部分并保留余数
(符号轴用向零取整,保证正负方向时序对称)。10 px/s 时一个 tick 只走
0.04 px,累加器约 25 个 tick 发出 1 px,视觉上是连续微动而非卡住再猛跳。

斜向 = 两个正交方向同时按下:分量速度 = v * diagScale,默认 0.7071 时
斜向合速度与直向相同(各向同性),避免 Windows 鼠标键斜向快 41% 的问题。

`dt` 必须用 `QueryPerformanceCounter` 实测,不能用名义 4 ms;定时器抖动
会让速度忽快忽慢,这正是"发木"的来源之一。

## 时序与线程

| 线程 | 职责 | 要点 |
|---|---|---|
| 主线程 | 窗口、消息循环、托盘、ImGui 渲染 | 渲染卡顿不影响移动;窗口隐藏时 WaitMessage |
| 钩子线程 | `WH_KEYBOARD_LL`,识别扫描码,过滤按键重复,写方向位图 | 只做判断,不产生位移 |
| 引擎线程 | 按住期间每 4 ms 算速度、累加、`SendInput` | 空闲阻塞在事件上(CPU 0) |

共享状态只有:方向位图(`std::atomic`)、参数快照
(`SRWLOCK` 保护)、启用开关(atomic)。

**引擎的时序设计**(实测后修正):最初打算用
`CREATE_WAITABLE_TIMER_HIGH_RESOLUTION` 的 4 ms 周期定时器常转,
实测它会为精确到期点自旋,常转吃 ~4-5% CPU。最终形态:

- **空闲(无按键)**:引擎线程阻塞在 auto-reset 事件上,钩子
  `setInput()` 时 `SetEvent` 立即唤醒;实测空闲 CPU 为 0。
- **活动(有按键)**:`timeBeginPeriod(1)` + `Sleep(4)` 循环,
  全部方向键松开即退回事件等待并 `timeEndPeriod(1)`。
- `dt` 用 `QueryPerformanceCounter` 实测,Sleep 的 ±1 ms 抖动被
  实测 dt 精确补偿,位移总量仍是速度对时间的严格积分
  (实测 400 ms 慢速位移 14 px,理论 14.7)。

两个必须处理的细节:

- **用扫描码绑定,不能用虚拟键码**:NumLock 关闭时数字键盘 8 产生
  `VK_UP`,与方向键撞车;扫描码唯一且不受 NumLock 影响(扩展键用
  E0 位区分,如主 Enter 0x1C 与小键盘 Enter E0 1C)。
- 钩子必须**吞掉**已绑定的键(返回非零),否则按住 8 会同时移动光标;
  长按产生的重复 down 事件用按下状态表过滤,否则 ramp 会被反复重置。

按键重复:LL 钩子的 `KBDLLHOOKSTRUCT` 不携带 repeat 位,因此对每个
扫描码维护"是否已按下"状态,已按下再收到 down 即为重复,忽略。

注入事件不额外过滤(本工具只注入鼠标事件,不会自反馈;验收脚本用
`SendInput` 注入键盘按键走的就是这条路径)。

## 按键语义(默认 = Windows 鼠标键数字键盘)

- 8/2/4/6:上/下/左/右;7/9/1/3:斜向(斜向即同时置两个方向位)
- 5:左键单击;0:按住左键(拖拽);.(Decimal):释放按住的键
- +:滚轮上;-:滚轮下
- 右键/中键默认不绑定,可在面板里捕获

绑定表 1:1(一个键一个动作),面板捕获:点击行 → "按任意键…" →
钩子吞下一个 down 记扫描码;Esc 取消;键冲突(两行动作绑同一键)拒绝
并提示。

## 代码结构

```
mousekey/
  CMakeLists.txt
  src/
    main.cpp        单实例、消息循环入口
    app.h/.cpp      组装: config → inject → engine → hook → tray/ui
    config.h/.cpp   MotionParams + 键位表 + INI 读写 + 默认值
    hook.h/.cpp     LL 钩子、扫描码表、捕获模式(纯逻辑与线程壳分离)
    engine.h/.cpp   定时器线程、加速曲线、亚像素累加(纯数学核心可测)
    inject.h/.cpp   SendInput 封装(move / wheel / button)
    tray.h/.cpp     Shell_NotifyIcon、菜单、启用态图标
    ui.h/.cpp       ImGui 参数面板 + 键位捕获行
  tests/            doctest 单元测试(纯逻辑)
  third_party/imgui/
  res/mousekey_on.ico
  res/mousekey_off.ico
```

配置存 exe 旁的 `mousekey.ini`,可直接手改,不用注册表。
单实例:命名互斥体,二次启动向首个实例发消息打开设置后退出。

## 验收标准

1. **曲线**:按住 2 s,单步驱动 tick,检查 ramp 达到 vMax 的时间误差
   ≤ 1 tick,v 单调不减。
2. **慢速精度**:vStart=10、按住 1 s,总位移 10 px ± 1;任意 100 ms
   窗口内位移不为 0。
3. **斜向**:45° 按住 1 s,|dx − dy| ≤ 1。
4. **手测**:3840×2160 屏对角全速 ≤ 1.5 s;1 px 级微调可复现。

1–3 由单元测试确定性覆盖;另提供可选 CSV tick 日志(config `csvLog=1`)
供真机回归。第 4 条由使用者在真机手测。

## 明确不做

惯性滑行、按应用切换配置、连点、多套配置、开机自启(可后加)、
按住热键切换开关(托盘/面板切换已足够)。
